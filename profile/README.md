用政府開放資料，看全臺各縣市的即時狀況。

臺灣儀表板是雲際科技工作室的公益專案。我們把各機關的開放資料整理成圖表與地圖，涵蓋天氣、空品、水情、電力、交通與防災，並長期保存歷史資料。

## 專案

| 專案 | 說明 |
|---|---|
| [Taiwan-Dashboard](https://github.com/dashboard-tw/Taiwan-Dashboard) | 網站與開放資料 API 的原始碼，後端是 Go，前端是 Vue 3 |
